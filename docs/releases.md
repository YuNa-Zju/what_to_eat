# 发布记录

## v0.3.0 · 2026-10-10

这一版将网站改为手写菜单，并整合饭店资料、地图和推荐体验。

- 自托管分片霞鹜文楷、暖色纯色底面与疏落碎金，明暗模式跟随系统；固定顶部栏，桌面书签目录、手机底部导航，弹窗沿用菜单主题。
- 选餐首页精简为一屏，候选名单与近期排除项收进搜索面板；分享保留瀑布流，历史按日期组成账本，统计按需展开。
- 首次打开逐笔绘制面碗，切页按目录顺序翻动并保留阅读位置；抽选先确定加权结果，再连续减速停在同一店名，支持减少动态效果。
- 个人推荐同时避开个人与聚餐窗口，两边长度独立，重复饭店只排除一次；喜好仍只使用当前模式的评价与频率。可主动开启距离参考，用直线距离温和调整概率；候选为空时不自动放宽窗口。
- 饭店目录与地图可切换，点击直接打开完整可编辑资料，支持封面、地址、地点搜索、地图选点及拖动标记；地图自适应剩余空间，无地址时搜索栏预填饭店名称。
- 取消饭店候选／不候选的区分，所有饭店均可参与推荐，旧停用标记不再影响推荐或记饭；历史和分享保留。
- 选图后压缩并提前上传，显示进度、支持失败重试和取消；封面与分享共用 WebP 压缩、MD5 和完整字节去重，最后一个有效引用移除后才清理文件。
- 点赞、用餐及饭店编辑使用实体级乐观更新，轮询不会覆盖待提交修改，失败仅回滚对应操作。

发布检查通过前端生产构建、24 项前端逻辑测试、24 项 Rust 测试及 Rust 格式检查，覆盖窗口并集、距离权重、乐观更新冲突、旧数据迁移与图片引用清理。已有桌面及模拟手机预览验证记录；真实手机输入法、触控和目标 Linux 部署仍待验收。前端主包仍有超过 500 kB 的构建提示，不阻断构建。

从 v0.2.1 升级前备份完整 `data` 目录，再一起更新 Rust 程序和前端产物；启动自动执行 `0006_photo_uploads.sql` 与 `0007_restaurant_details.sql`。已有照片不会批量改写，旧饭店新增资料为空。

本版提供源码，不包含平台预编译程序或线上部署。高德 API Key、安全密钥、本地 `.env`、数据库及上传照片均不随发布提供；地图由部署者自行配置，参见 [高德接入说明](maps.md)。未配置地图时，其他功能仍可使用。

## v0.2.1 · 2026-10-09

- 首次访问使用聚光高亮逐步讲解真实按钮，覆盖聚餐／个人模式、抽选、窗口、记录、分享、搜索、历史与饭店管理；支持直接操作、前后翻步、退出和重新打开。表单打开时暂停引导，关闭后续教；浏览教程不覆盖已有草稿。
- 移除日常页面和表单中重复的用法说明，保留字段、状态、错误及删除确认信息。
- 分享筛选与排序收进搜索框右侧的齿轮弹窗，应用后显示可逐项清除的条件标签，支持一键清空；取消不更改已应用条件，日期倒置时阻止应用。
- 合并 HTTP 缓存：图片和带哈希的静态文件可复用浏览器缓存，饭店名单使用 ETag 校验，其他 API 保持不缓存。
- “记一顿”和“写分享”共用表单，可选择只记用餐、记录并分享或仅分享；草稿保留范围、金额和评价。
- 用餐和分享可选填写本次总花费，按人民币精确到分。共享用餐修改后同步关联分享，已有数据金额留空。
- 加入跟随系统实时切换的暗色模式，覆盖导航、卡片、表单、日历、Markdown、弹窗和 SVG 图表／插画。
- 浏览器支持时，地址栏和原生控件的颜色也跟随系统；保持现有浅色外观和暖橙风格。

暗色模式已通过前端生产构建，并检查主要文字和按钮的色值对比度；浏览器实际切换和真机显示尚未验收。

首次使用引导已通过前端生产构建，并在独立临时服务中检查首次弹出、模式切换、抽选、真实表单打开／关闭后继续、跨页、完成与退出记忆、重新打开和原草稿保留；查看了 390 像素手机与 1280 像素桌面宽度。未新增用餐或帖子，控制台未发现警告和错误；真机触控仍待验收。

筛选弹窗已通过前端生产构建，浏览器中检查组合条件应用、取消保留原条件、标签逐项清除、一键清空、手机日期范围校验，以及关闭后焦点返回齿轮。

金额与统一流程已通过前后端构建、13 项接口与图片测试、3 项 HTTP 缓存测试和 14 项前端逻辑测试。独立临时服务中已实际操作只记用餐、从记录补发分享、同时记录并分享、仅分享四条路径，确认金额显示及不重复记账。新增 `0005_meal_costs.sql` 迁移，需随程序更新执行。

从 v0.2.0 升级时先备份数据库与照片，再一起更新 Rust 程序和前端产物，保留 `data` 目录。启动会自动执行 `0005_meal_costs.sql`，旧记录的花费保留为空。发布提供源码，不包含平台预编译程序；本次未更新线上服务。

## v0.2.0 · 2026-10-09

改进分享浏览、编辑和手机输入体验。

- 桌面双列瀑布流，短列继续紧凑排列；手机保持单列。多张图片默认折叠，封面右下角显示剩余数量，点击打开画廊。
- 分享支持关键词、饭店、昵称、日期筛选及多种排序；点击用餐记录查看关联分享。
- 未绑定用餐的分享可以编辑饭店、日期与照片；绑定分享锁定饭店和日期，用餐记录变更同步到关联分享。
- 饭店模糊搜索、自定义日历和选择控件，修复手机日期栏溢出并调整软键盘出现时的弹窗。
- 新上传照片在服务端校正方向、缩放、压缩，保留透明背景；现有图片不批量改写。
- 成功发布后在当前浏览器记住昵称，下次自动填写；草稿优先，清空后发布会记住匿名选择。

本机 Rust 构建、前端生产构建、11 项后端及 12 项前端测试通过，已检查桌面瀑布流、画廊与模拟手机尺寸。昵称记忆最后加入并通过构建，按发布要求未继续增加测试；真实 iPhone 输入法仍待验收。

从 v0.1.0 升级时先备份数据库与照片，再一起更新程序和前端产物。启动自动执行 `0003` 分享查询索引与 `0004` 失效用餐关联清理迁移。此发布提供源码，未代替线上部署，也不包含平台预编译程序。

## v0.1.0 · 2026-10-08

首个可运行版本，用于朋友小团体维护饭店名单、挑选下一顿、记录和分享用餐。

- 共享与本地用餐历史，默认避开最近 5 家不同饭店，可调整窗口。
- 完整历史时间线、筛选、统计与用餐评价，按评价和频率微调推荐概率。
- Markdown 分享、匿名或昵称、赞踩、照片附件；UUID 存储、MD5 与文件内容去重、最后一个引用删除后清理。
- React、Tailwind CSS、shadcn/ui 暖橙界面，响应式布局、SVG 插画和名字滚动动画，手机编辑与预览。
- Rust 托管网页和 API，SQLite 持久化，提供部署、备份、接口和 Gitflow 说明。

本机 Rust 开发构建、前端生产构建、7 项后端及 8 项前端测试通过。已在桌面与 390 × 844 手机尺寸检查页面、Markdown 预览、动画和弹窗排版。远程服务器部署及真机软键盘、相册仍待验收，详见 [验证记录](verification.md)。
