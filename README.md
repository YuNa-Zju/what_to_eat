# 今天吃什么

少一点纠结，多一点好好吃饭。一个适合朋友小团体共同使用的用餐选择与分享网页。

**线上使用需要更新程序、静态资源和数据库迁移。** 已发布版本的检查范围见 [验证记录](docs/verification.md)，后续功能见 [待发布更新](docs/releases.md)。

## 可以做什么

- 共用饭店名单，初始包含 30 家；任何访问者都能新增、改名、停用与恢复。
- 在“我们聚餐”和“我自己吃”之间切换，分别维护云端历史和浏览器本地历史。
- 默认避开最近 **5 家不同饭店**，从剩余饭店中按喜好概率推荐；也可以手动记一顿、补记日期、编辑或删除记录。
- 窗口长度可调整为 1–100。重复吃同一家只占一个位置，完整历史一直保留。
- 每顿可评价“喜欢／一般／不喜欢”；以评价为主、用餐频率为辅微调推荐概率，新店保留探索机会。
- 独立用餐历史页面提供时间线、日期／饭店／评价筛选、近两周统计和每家饭店的当前推荐概率。
- 匿名或填写昵称发布 Markdown 分享，支持标题、列表、引用、链接、代码和表格。成功发布后在本机记住昵称，下次自动填入；草稿优先，清空后发布会记住匿名选择。
- 分享在桌面按双列瀑布流展示，手机为单列，支持关键词、饭店、昵称、用餐日期组合筛选，以及发布时间、用餐日期和点赞数排序。点击用餐记录可查看其关联分享。
- 饭店选择支持中文片段模糊搜索；日期、选择框和选中状态统一使用自定义样式。
- 手机编辑器提供格式工具栏、编辑/预览切换及相册多选；桌面提供并排预览。布局适配手机、平板与桌面。
- 暖橙与奶油色界面，手绘 SVG 餐碗和骰子、餐厅名字滚动动画；系统减少动态效果设置会关闭装饰动画。
- 明暗主题自动跟随系统，切换时立即生效；暗色使用暖炭灰底色与柔和琥珀色，包含编辑器、弹窗、图表和插画。
- 每帖可上传 6 张照片，支持 JPEG、PNG、WebP，每张输入最多 10 MiB、2500 万像素。服务端自动缩放至最长边 1600 像素并压缩，保留透明背景与正确方向。
- 多图默认显示一张封面，右下角显示剩余张数；点击打开支持方向键、滑动与缩略图的画廊。
- 编辑分享可修改昵称、正文和照片；未绑定用餐的分享也可修改饭店和日期，已绑定项锁定。
- 支持点赞、点踩、取消投票。任何访问者都能修改或删除分享，无需账号。
- MD5 查找重复图片，再核对文件内容；UUID 文件名与数据库引用关系共同管理照片，最后一个引用删除后才清理文件。

## 技术与目录

前端：React、TypeScript、Vite、Tailwind CSS 4、shadcn/ui。Markdown 使用 `react-markdown`、`remark-gfm` 和 `rehype-sanitize`。

后端：Rust、Axum、tower-http、SQLx、SQLite。Rust 同时提供静态网页、API 和图片。Node 只用于前端开发与构建，生产环境无需 Node 服务或单独的数据库服务。

```text
frontend/       React 网页、shadcn/ui 组件、前端测试
src/            Rust API、图片处理、数据库初始化
migrations/     SQLite 迁移
resources/      初始饭店名单
tests/          Rust 接口及图片生命周期测试
deploy/         systemd、Nginx 配置示例
docs/           部署、接口、Gitflow 和验证说明
data/           运行时生成，不进入 Git
```

## 以后如何构建和运行

构建环境需要 Rust 稳定工具链、C 编译工具链、Node.js 22.12+ 或兼容的更新 LTS，以及 npm。生产环境的 release 编译和部署仍需在目标平台执行。

```sh
cd frontend
npm ci
npm run build
cd ..
cargo build --release --locked
./target/release/what-to-eat
```

默认访问 `http://127.0.0.1:3000`。首次启动自动创建数据库、执行迁移并加入初始饭店。详细操作见 [部署说明](docs/deployment.md)。

## 开发

两个终端分别启动后端和 Vite：

```sh
# 仓库根目录。开发网页应访问 Vite 的 5173 端口。
STATIC_DIR=frontend cargo run
```

```sh
cd frontend
npm ci
npm run dev
```

访问 `http://127.0.0.1:5173`，Vite 将 `/api` 和 `/media` 转发给 Rust。开发时的 `STATIC_DIR=frontend` 仅用于启动 API 服务，TSX 和样式由 Vite 处理；生产环境改为构建后的 `frontend/dist`。

## 使用约定

- 这是共同维护的小团体空间，没有登录、管理员或内容所有权限制；昵称只用于展示。
- 点赞身份保存在浏览器 Cookie 中，清除 Cookie 或换设备会成为新的匿名身份。
- 本地历史、窗口设置、新帖文字草稿及最近发布昵称保存在当前浏览器；清除网站数据会清除这些内容。草稿不包含照片，编辑已有分享不会改写默认昵称。
- 用餐历史按用餐日期排序，同日按录入时间排序；本地日期使用访问者当前时区。
- 发帖默认不记账；可选记入共享或本地历史，从已有历史分享不会重复记账。删除帖子不删除用餐历史。
- Markdown 原始 HTML 不执行，外部图片语法只显示说明文字；照片通过上传附件展示，以统一处理存储、去重和删除。
- 停用饭店不再进入随机候选，但其历史和分享保留。
- 每 30 秒及页面重新获得焦点时同步共享内容。多人同时编辑同一条内容，以最后一次成功保存为准。
- 服务设计为**单进程、单实例**，SQLite 和照片目录由同一个 Rust 服务管理。
